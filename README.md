Добавил web ui интерфейс для более удобного ввода и проверки високосного года. 

Проверки:  
- на отрицательное число
- на 0
- на буквы
- на спецсимволы

Если год високосный отображается зеленым.  
Если не високосный или ошибка то красным.  
Реализован список с последними введенными 20-ти годами.

Запуск python main.py
